Section 1

Why C++? Real-World Power & How Code Runs

Why learn C++? C++ isn't just a classroom language—it is the high-performance engine behind the most advanced technology on Earth! When microsecond speed, hardware control, and safety matter, engineers choose C++.

Self-Driving Vehicles

Autonomous vehicles use C++ to process LIDAR & camera data in milliseconds to safely navigate city traffic.

AAA Video Games

3D Game Engines use C++ to render high-detail graphics, compute physics, and run game logic at over 120 FPS.

Advanced Robotics

Boston Dynamics and VEX robots rely on C++ for real-time motor control, balance, and spatial movement.

How Code Runs (The Compilation Process): Robot microchips cannot read C++ text directly. Before execution, your human-readable Source Code must pass through a Compiler—a program that checks for errors and translates C++ text into binary Machine Code (1s and 0s).

In C++, every single instruction or command is called a Statement. A critical rule of C++ syntax is that each C++ instruction must end with a semicolon (;). The semicolon tells the compiler where one command finishes and the next command begins.

1

Every program requires an Entry Function named the Main Function (main()), where code starts running line by line.

MAIN.CPP - MINIMAL C++ PROGRAM STRUCTURE
// Every C++ program begins execution inside the main() entry function
int main() {
    // Instructions execute step-by-step from top to bottom
    return 0; // Signals successful program completion to the brain;
}

COMMON PITFALL: MISSING SEMICOLON (;)

Forgetting to end a C++ statement with a semicolon is the #1 beginner error. Without a semicolon, the compiler gets confused and merges lines together, resulting in a syntax build error!

SECTION 1 VOCABULARY REVIEW

  • Compiler: A software tool that checks C++ source code for syntax errors and translates it into binary machine code.
  • Source Code: The human-readable C++ text instructions written by a programmer.
  • Machine Code: Low-level binary (1s and 0s) instructions that microprocessors directly execute.
  • Statement: A single complete command in C++. Every C++ statement must end with a semicolon (;).
  • Semicolon (;): The mandatory punctuation mark used to terminate C++ statements.
  • Main Function (main()): The essential entry function where C++ program execution begins.

Storing Data with C++ Variables

A Variable is a named storage container in memory designed to hold a data value that can change while the program runs. In C++, you must explicitly specify a variable's Data Type before using it—a process known as variable Declaration. Assigning a starting value when creating a variable is called Initialization.

Data Type Data Stored Example Value Declaration Example
Integer (int) Integers (Whole numbers) 5, -12, 100 int targetID = 3;
Floating-point (float) Floating-point numbers (Decimals) 15.5, 0.25 float distance = 15.5;
Boolean (bool) Boolean flags (True/False) true, false bool isReady = true;
VARIABLES.CPP - DECLARING DATA TYPES
int itemQuantity = 4;     // Whole number counter
float speedSetting = 85.5; // Decimal value
bool engineActive = true;  // State flag

COMMON PITFALL: UNINITIALIZED VARIABLES

If you declare a variable (e.g., int score;) without giving it an initial value before reading it, the variable will hold random garbage data left over in RAM memory, causing unpredictable robot behavior!

SECTION 3 VOCABULARY REVIEW

  • Variable: A named location in computer memory used to store data values.
  • Data Type: The specifier that tells C++ what kind of data (integer, decimal, true/false) a variable holds.
  • Integer (int): A data type used to store whole numbers without fractions or decimals.
  • Floating-point (float): A data type used to store real numbers containing decimal points.
  • Boolean (bool): A logical data type that stores either true or false.
  • Declaration: Introducing a variable to C++ by defining its data type and name.
  • Initialization: Setting an initial value for a variable when it is created.

Section 4

Arithmetic Expressions & Operators

An Arithmetic Expression combines variables, numeric values (called Operands), and mathematical symbol Operators to calculate dynamic new values. C++ uses standard arithmetic operators: Addition (+), Subtraction (-), Multiplication (*), and Division (/).

Operator precedence decides which operation runs first. Multiplication and division happen before addition and subtraction. 15 - 3 * 2 is 15 - 6, which is 9. Parentheses run first, so (15 - 3) * 2 is 24.

EXPRESSIONS.CPP - MATH OPERATIONS
float startPos = 100.0;
float endPos = 450.0;
// Expression calculates distance between coordinates
float distance = endPos - startPos; // Evaluates to 350.0

// Updating variable values dynamically
int score = 10;
score = score + 5; // New score value is 15

COMMON PITFALL: INTEGER DIVISION TRUNCATION

Dividing two integers in C++ produces an integer result! For example, 5 / 2 evaluates to 2 instead of 2.5 because C++ chops off (truncates) the remainder when both numbers are int types. To preserve decimals, ensure at least one operand is a decimal float like 5.0 / 2.

SECTION 4 VOCABULARY REVIEW

  • Arithmetic Expression: A combination of constants, variables, and mathematical operators that calculates a single numerical output.
  • Operator: Symbols like +, -, *, / that instruct C++ to perform mathematical operations.
  • Operand: The values or variables acted upon by an operator in an expression.
  • Integer Division: Division performed between two whole numbers that automatically truncates any fractional decimal remainder.
  • Operator Precedence: The order C++ uses when an expression has more than one operator. * and / run before + and -. Parentheses run first.

Tracing Code on Paper

Before a program runs on the robot, walk through it yourself. Read one statement, do exactly what that line does, and write the result down. Then go to the next line. This is called tracing.

Record each result in a variable table: one row per variable. When a line creates a variable, add a row and write its name and starting value. When a later line stores a new value in that same variable, draw a line through the old value and write the new one beside it. Do not erase the old value.

          Section 6
          
Control Flow: Basic if / else Statements

        

        
By default, program Control Flow follows sequential line-by-line execution. Introducing Decision-Making through a Conditional Statement allows programs to branch. An if Statement checks a condition, while an else Statement provides an alternate fallback branch. Code inside each branch is enclosed within a curly-brace Code Block {}.


        
BRANCHING.CPP - SINGLE BRANCH EXECUTION


bool systemReady = true;

if (systemReady) {
    // Runs ONLY when systemReady is true
    int status = 1;
} else {
    // Runs ONLY when systemReady is false
    int status = 0;
}


        
DECISION RULE: If the condition inside if (...) evaluates to true, the top block executes and the else block is completely skipped. If it is false, the if block is skipped and the else block executes.


        

          
COMMON PITFALL: MISSING CURLY BRACES {}

          
While C++ allows single-line if statements without curly braces, omitting `{}` for multi-line code means only the first line is controlled by the condition! Always use curly braces to cleanly define your code block.

        


        

          
SECTION 5 VOCABULARY REVIEW

          
    
            
  • Control Flow: The specific order in which individual statements and instructions are executed in a program.
    • 
            
  • Decision-Making: The ability of a program to execute different code pathways based on dynamic conditions.
    • 
            
  • Conditional Statement: A programming construct (like if or else) that selects execution paths based on true/false conditions.
    • 
            
  • if Statement: A statement that executes its code block only if its condition evaluates to true.
    • 
            
  • else Statement: An optional statement paired with if that executes its code block when the if condition evaluates to false.
    • 
            
  • Code Block: A group of C++ statements enclosed within opening and closing curly braces { }.

Relational Operators & Boolean Expressions

        

        
A Relational Operator compares two values to construct a Boolean Expression that evaluates strictly to true or false. Understanding the difference between the Equality Operator (==) and the Assignment Operator (=) is essential for correct logic.


        

          
            

              Operator
              Meaning
              Code Example
              Evaluation
            

          
          
            

              ==
              Equal to
              (50 == 50)
              true
            

            

              !=
              Not equal to
              (10 != 5)
              true
            

            

              < / >
              Less than / Greater than
              (15 > 20)
              false
            

            

              <= / >=
              Less/Greater than or equal
              (20 >= 20)
              true
            

          
        


        

          
COMMON PITFALL: ASSIGNMENT VS EQUALITY

          
A single = is the assignment operator used to store values into variables (x = 5;). A double == is the equality comparison operator (if (x == 5)). Accidentally writing a single = inside an if condition overwrites your variable value and always forces the condition to evaluate as true!

        


        
RELATIONAL DEMO.CPP - EVALUATING CONDITIONS


int speed = 45;
// Relational comparison evaluates to boolean true
bool isFast = (speed > 40);

if (speed >= 50) {
    // Triggers if speed reaches 50 or higher
} else {
    // Triggers if speed is strictly below 50
}


        

          
SECTION 6 VOCABULARY REVIEW

    • 
            
  • Boolean Expression: A logical statement or expression that produces a value of either true or false.
    • 
            
  • Equality Operator (==): The relational operator used to test if two values are equal.
    • 
            
  • Assignment Operator (=): The operator used to assign a new value into a variable memory location.

          Section 8
          
Constant Variables (const)

        

        
A Constant Variable is created using the const Keyword. Declaring a constant marks the variable as Read-Only. Once assigned during initial declaration, its value can never be altered or reassigned elsewhere in your program.


        
CONSTANTS.CPP - CREATING READ-ONLY PARAMETERS


// Naming convention: kCamelCase style for constants
const float kPi = 3.14159;
const int kMaxSpeed = 100;

// kMaxSpeed = 120; <-- ERROR: Cannot modify read-only variable!


        

          
COMMON PITFALL: MODIFYING CONSTANT VARIABLES

          
Attempting to reassign a new value to a const variable anywhere in code (e.g., kMaxSpeed = 80;) causes an immediate compiler error that stops your program from building.

        


        

          
SECTION 7 VOCABULARY REVIEW

          
    
            
  • Constant Variable: A variable whose stored value is fixed and protected from being modified during runtime.
    • 
            
  • const Keyword: The C++ qualifier prefix used to declare a variable as immutable and read-only.
    • 
            
  • Read-Only: A memory protection state preventing data modification after initial declaration.
    •

Displaying Data on VEX Brain Screen

        

        
VEX C++ provides specialized screen output functions that draw on the physical display Screen Buffer. Text layout is controlled by positioning the active text Cursor.


        

          
            

              Screen Command
              Purpose & Description
            

          
          
            

              Brain.Screen.clearScreen();
              Erases all content from the current screen buffer.
            

            

              Brain.Screen.setCursor(row, col);
              Positions text cursor at specified row and column.
            

            

              Brain.Screen.print("Text");
              Displays literal text string on the screen.
            

            

              Brain.Screen.newLine();
              Advances cursor to the beginning of the next row.
            

          
        


        
To print variable values, place a Format Specifier placeholder inside the text string: %d for integers (int), and %f for decimals (float).


        
BRAIN SCREEN.CPP - SCREEN PRINTING SYNTAX


int count = 10;
float temp = 98.6;

Brain.Screen.clearScreen();
Brain.Screen.setCursor(1, 1);
Brain.Screen.print("Count: %d", count); // Prints integer
Brain.Screen.newLine();
Brain.Screen.print("Temp: %f", temp);   // Prints floating decimal


        

          
COMMON PITFALL: MISMATCHED FORMAT SPECIFIERS

          
Passing a floating-point decimal variable into an integer format specifier (%d) without type casting causes garbage digits to appear on the screen display!

  • Screen Buffer: The video memory holding pixel and character data displayed on the VEX Brain LCD.

Control Flow: Repetition with for Loops

        

        
A for Loop repeats a code block multiple times. Each pass through the loop is called an Iteration. A Loop Counter variable manages the loop state, updated at the end of each pass using the Increment Operator (++).


        
FOR_LOOP.CPP - REPEATING INSTRUCTIONS


// Header parts: Init (int i = 0); Condition (i < 5); Increment (i++)
for (int i = 0; i < 5; i++) {
    Brain.Screen.print("*");
}
// Output on screen: *****


        

          
COMMON PITFALL: OFF-BY-ONE ERRORS & INFINITE LOOPS

          
Confusing < with <= causes loops to run one time too many (an off-by-one error). Forgetting to update your loop counter variable (e.g. omitting i++) creates an infinite loop that freezes your robot program!

        


        

          
SECTION 9 VOCABULARY REVIEW

          
    
            
  • for Loop: A loop control structure that iterates code a specific number of times based on a counter condition.
    • 
            
  • Iteration: A single complete execution pass through a loop's code block.
    • 
            
  • Loop Counter: An integer variable (typically i) tracking iteration passes.
    • 
            
  • Increment Operator (++): An operator that increases a variable's value by 1 (e.g., i++).
    •

Type Casting with static_cast<int>

        

        
Type Casting is an Explicit Conversion technique used to convert data from one type to another. Writing static_cast<int>(value) converts a decimal (float) into an integer (int) by performing Truncation—dropping the fractional decimal portion entirely.


        
TYPE_CAST.CPP - CONVERTING TYPES FOR SCREEN PRINTING


float speedVal = 85.75;

// Cast float to int so it safely matches the %d format specifier
Brain.Screen.print("Speed: %d", static_cast<int>(speedVal));
// Screen Output: Speed: 85


        

          
COMMON PITFALL: PRECISION LOSS DURING TRUNCATION

          
Remember that static_cast<int> does NOT round numbers to the nearest whole integer. Casting 9.99 truncates the `.99` completely, producing `9`. If rounding is required, handle decimal math explicitly before casting.

        


        

          
SECTION 10 VOCABULARY REVIEW

          
    
            
  • Type Casting: Converting a variable value explicitly from one data type to another.
    • 
            
  • Explicit Conversion: Manually commanding C++ to convert a type using operators like static_cast.
    • 
            
  • Truncation: The removal of the decimal fractional portion of a number without mathematical rounding.
    • 
            
  • static_cast: The standard compile-time type conversion operator in C++.
    •
